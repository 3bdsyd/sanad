# تصميم فرصة بحسب المرجع

> هذه وثيقة للنسخة السابقة. التصميم الحالي يلغي البوب أب ويستخدم صفحات كاملة وألواناً موحّدة؛ راجع [إعادة التصميم](redesign-ux.md).

المرجع ثلاث شاشات لتطبيق عمل: بداية برسوم 3D، اكتشاف فرص، تفاصيل فرصة. أعيد تكوينها بمحتوى فرصة العربي لسوريا مع الحفاظ على التصفح دون حساب والتواصل المباشر. لا ينسخ التطبيق شعارات Google وMicrosoft أو أعداد المتقدمين من موك أب لتجنب نسبة فرص وهمية لشركات حقيقية.

## النظام البصري

| العنصر | التنفيذ |
|---|---|
| خلفية كاملة | `#5B88B8` → `#8AAACC` → `#CADBEA` مع إضاءة ناعمة جانبية |
| الأزرار والراتب | `#467BB6` |
| العنوان على الأزرق | أبيض، Vazirmatn Bold |
| نص البطاقات | `#303438` و`#6E7880` |
| البطاقة | أبيض ثلجي `#F4F8FA`، زاوية 35، حد أبيض رفيع |
| البحث | كبسولة شفافة، حقل داخلي شفاف، دائرة بيضاء للفلاتر |
| العلامات | دوائر بيضاء مع رسم مجال أصلي متعدد الألوان |
| الأزرار | كبسولات زرقاء، أيقونات خطية دائرية |
| التفاصيل | عنوان أبيض وعلامة وسطية، لوحة فاتحة مع الراتب والنص ونقاط المتطلبات وزر التواصل |

شاشة الترحيب تظهر مرة واحدة ويمكن تخطيها بنفس خطوة البدء؛ فشل حفظ التفضيل لا يمنع التصفح. يمكن العودة إليها من كبسولة «أهلاً فيك» ثم «شاشة البداية». [رسوم البداية وأوامر توليدها](illustration-assets.md) محلية ولا تحتاج اتصالاً.

جرس الرئيسية يفتح أحدث الفرص الموجودة؛ لا يطلب إشعارات ولا يوهم بوجود اشتراك دفع. القلب يحفظ محلياً. شرائح البحث والفلاتر والأرقام والنشر تحتفظ بمنطق التطبيق. الرواتب تعزل اتجاه الرقم لعرض الحد الأدنى قبل الأعلى داخل العربية.

## ناف بار سورفا

نُقلت طريقة تكامل سورفا مع UIKit: `UiKitView` يعرض `UITabBar` فعلياً، وقناة لكل instance تحدث الاختيار وتستقبل الارتفاع. لا تعديل على مشروع سورفا. الوجهات الثلاث تخص فرصة: الفرص، المحفوظة، أضف فرصة. النظام يعرض Liquid Glass على iOS 26. Android والويب لهما بديل Flutter زجاجي مع تحديد متحرك واحترام RTL وتكبير النص. راجع [تفاصيل iOS](native-ios.md).

## الوصول والتحقق

النص حي قابل لتكبير النظام، الديكور مستثنى من شجرة الوصول، الأزرار موسومة، وحركات البداية والتنقل تحترم Reduce Motion. صفحات البداية والمحتوى قابلة للتمرير على الشاشات القصيرة. تبقى بيانات الديمو معلّمة والاتصال الوهمي محجوباً.

اللقطات في [مجلد المعاينات](screenshots) تظهر البناء الفعلي بمحتوى عربي. المطابقة تتبع الألوان والتكوين والملمس؛ اختلاف اللغة والمحتوى وعناصر iOS النظامية يؤثر في القياسات، وليست نسخة بكسلية من الموك أب.

## نتيجة الفحص لهذه النسخة

- تنسيق Dart وتحليل Flutter: نجحا.
- بناء الويب: نجح؛ فحص المتصفح بقياس 390×844 و320×640 و1440×1000.
- جرى التحقق من الانتقال من الترحيب، ظهور الترحيب مرة واحدة، حفظ فرصة والعودة إليها، فتح التفاصيل، منع التواصل مع بيانات العرض، البحث عن Flutter، فلتر العمل عن بُعد، فتح الفلاتر وشاشة الإضافة وأحدث الفرص. لم يسجل المتصفح أخطاء runtime.
- نجح أيضاً فحص نقر فعلي عبر canvas لزر «تخطي» والتبويبات الثلاثة؛ زخرفة الترحيب تتجاهل اللمس حتى لا تغطي الأزرار.
