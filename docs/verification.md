# التحقق المنفذ

تم في 24 سبتمبر 2026 باستخدام Flutter المثبت وXcode 26.6.

- `dart format .` و`flutter analyze`: دون ملاحظات.
- `flutter build web`: بناء ناجح، تشغيل Chrome بأحجام 1440 و390 و360 بكسل دون page errors في المسارات المفحوصة.
- تجربة واجهة: حفظ فرصة واستمرارها بعد التحميل، تفاصيل، حماية الاتصال التجريبي، بحث بلا نتائج وإعادة ضبط، فلاتر سريعة وشاملة، حقول مطلوبة، إضافة بخطوتين مع أرقام عربية، واستمرار الإعلان المحلي بعد إعادة الفتح.
- تجربة فعلية من Flutter Web إلى خادم SQLite محلي معزول: قراءة فرصة، نشر إعلان pending، التأكد من غيابه عن الواجهة العامة قبل المراجعة، موافقة المشرف، ظهوره للعامة، إعادة تحميل وإدارة بمفتاح التخزين الآمن، حذف المالك وزواله من القائمة العامة.
- `server/smoke_test.py`: 44 فحص API ناجحاً وفق [دليل الخادم](backend.md)، بما فيه HTTP loopback وصلاحيات وأمان العقد والانتهاء.
- `flutter build ios --simulator --debug`: بناء ناجح. تركيب وتشغيل على iPhone Simulator iOS26.5، مع SF Symbols وناف بار UIKit glass مرئي فعلياً؛ تفاصيل القياسات والفحص في [وثيقة iOS](native-ios.md).

لم نُجرِ إرسال بريد أو مكالمة فعلية، ولم نختبر الإحساس بالهزات على جهاز حقيقي. لم يتم نشر خادم عام أو تشغيل Docker (غير مثبت) أو توقيع IPA أو رفع متجر. لم يُنفّذ بناء Android. لم يتم اختبار ضغط تجاري أو تدقيق أمني مستقل. لا تُعمّم نتائج المقاسات والمسارات المفحوصة على كل أجهزة المستخدمين أو جميع أحجام الخط؛ اختبر جهاز iPhone فعلياً وخدمات الدعم قبل الإصدار.

أدوات فحص المتصفح المؤقتة خارج المشروع. لا يضاف إطار اختبارات Flutter أو متطلبات PR إلى المشروع.
