# لقيت — التصميم الحالي

التنفيذ موجود في هذا المشروع نفسه، في `lib/features/jobs/presentation`، وليس في نسخة مؤقتة. افتح مجلد `fursa` كاملاً في المحرر وشغّل `lib/main.dart`؛ مشروع `elearn` المجاور تطبيق تعليمي مستقل.

## التشغيل

```bash
cd /Users/apple/Projects/fursa
flutter pub get
flutter run
```

في VS Code اختَر إعداد **لقيت — Fursa**. إذا كانت جلسة قديمة تعمل، أوقفها ثم أعد التشغيل كاملاً لتضمين تغييرات iOS والألوان.

## الرحلة الجديدة

- رئيسية للبحث: مقدمة قصيرة تنكمش عند الكتابة، بحث مثبت، فلاتر سريعة قابلة للتبديل، وعدد نتائج واضح.
- كروت قابلة للمقارنة: الجهة، المسمّى، المكان، الدوام والخبرة، الراتب وفترته. لا أعداد متقدمين مختلقة.
- الفلاتر والإضافة والمعلومات صفحات عادية ذات رجوع واضح. الخيارات تتمدد داخل محتواها؛ أزيلت dialogs وbottom sheets وpopup menus وSnackBar من رحلات التطبيق.
- القلب يحمل الكارد إلى المحفوظة مع تراجع، والسحب بديل اختياري. إسقاط فرصة محفوظة لا يزيلها. موضع التمرير يبقى عند تبديل التبويبات.
- تفاصيل بهيدر ثابت ومنطقة تواصل واحدة. الإبلاغ والإخفاء وبديل نسخ التواصل داخل الصفحة. التحقق من صلاحية الإعلان ووسيلة التواصل بقي محفوظاً.
- إضافة بخطوتين مع تحقق من كل حقول الخطوة والتركيز على أول خطأ. Scaffold وحده يعالج مساحة الكيبورد. تأكيد المغادرة والنجاح داخل الصفحة.
- بحث وفلاتر ومحفوظات محلية. «على بالك» متابعة داخل التطبيق، وليست إشعارات دفع.

## الألوان والوصول

أزرق الإجراءات `#315F86`، النص `#192C3F`، الثانوي `#5B6C7D`، خلفية `#F5F7FA`، كروت بيضاء بزوايا 24 وحد `#E0E8EF`، إبراز `#E8F0F7`. خط Vazirmatn وRTL. الزجاج محصور في الناف بار؛ بطاقات القراءة معتمة. تبويبات الويب تدعم Tab وEnter وSpace، والعناوين تتكيف مع تكبير النص. Reduce Motion يتجاوز AnimatedSize عبر MotionSize لتجنب خطأ مدة الصفر.

استندت القرارات إلى [Apple للتغذية الراجعة](https://developer.apple.com/design/human-interface-guidelines/feedback)، و[Apple للتنقل](https://developer.apple.com/videos/play/wwdc2022/10001/)، و[WCAG لتباين النص](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum). هذا تطبيق لمبادئ تصميم، وليس شهادة مطابقة أو ضمان إقبال.

## الفحوص المنفذة على التصميم

- فحص Chrome شمل فتح الكارد بسرعة، تثبيت البحث، الحفظ والسحب الحقيقي، الفلترة وحفظها واستعادتها، النشر حتى النجاح، وتأكيد المغادرة داخل الصفحة. دون أخطاء Flutter في الفحص النهائي.
- فحص مستقل لتقليل الحركة والتحقق من الراتب، وواجهات 320×640 و390×844 والكمبيوتر، وتكبير الخط 200% دون أخطاء overflow في الشاشات المفحوصة.
- 3 فحوص XCTest مؤقتة نجحت على iPhone 17 / iOS 26.5: UIKit بثلاث وجهات، زر تواصل ثابت أثناء السكرول، صفحات كاملة، وإظهار حقل الوصف الخاطئ فوق الكيبورد العربي. لم يُختبر جهاز فعلي أو VoiceOver.
- أدوات الفحص المؤقتة خارج المشروع؛ لا إطار اختبارات أو سير PR مفروض.
